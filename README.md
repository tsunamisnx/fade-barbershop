# Барбершоп FADE — современный сайт

Современный стильный сайт для барбершопа с акцентом на атмосферу заведения, услуги и удобство записи.

## Основные возможности

* 💈 Информация о барбершопе
* ✂️ Каталог услуг и цен
* 👨‍💼 Раздел с мастерами
* 📅 Онлайн-запись на услугу
* 🖼️ Галерея работ и интерьера
* 📍 Контактная информация и расположение
* 📱 Адаптивная версия для мобильных устройств
* ✨ Плавные анимации и интерактивные элементы
* 🎨 Современный премиальный дизайн

## Технологии

* HTML5
* CSS3
* JavaScript
* Адаптивная вёрстка
* SVG

## О проекте

Проект разработан как концепт современного сайта для барбершопа.

Основная задача — создать стильный и удобный сайт, который одновременно передаёт атмосферу заведения, знакомит посетителя с услугами и мастерами и позволяет быстро записаться на процедуру.
